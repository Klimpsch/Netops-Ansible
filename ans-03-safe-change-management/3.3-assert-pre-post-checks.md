# 3.3 assert: pre and post checks

**Task:** write a change playbook that aborts, and rolls back, if OSPF neighbours drop.

## What you'll learn

| Concept | In one line |
|---|---|
| `register` | Saves a task's output in a variable |
| `set_fact` | Creates a new variable during the play |
| `regex_findall` | Finds every match of a pattern in some text |
| `assert` | Fails the play if a condition isn't true |
| `block` / `rescue` | "Try this. If anything fails, run that instead" |
| `pause` | Waits a set time |

## The plan

```
PRE-CHECK     count FULL OSPF neighbours  ──> 0?  ──> STOP, don't touch it
     │
CHANGE        set ip ospf cost 50 on Gi2
     │
WAIT          15 seconds
     │
POST-CHECK    count FULL neighbours again
     │
     ├── same or more  ──> ✅ save config
     └── fewer         ──> ❌ RESCUE: undo the change, then fail loudly
```

## Files

```
ansible-lab/
```

## The file explained

### `ospf-change.yml`

```yaml
---
- name: Change OSPF cost safely (abort if neighbours drop)
  hosts: R1
  gather_facts: false

  vars:
    change_interface: GigabitEthernet2
    new_cost: 50

  tasks:
    # ---------- PRE-CHECK ----------
    - name: Pre-check - get OSPF neighbours
      cisco.ios.ios_command:
        commands: show ip ospf neighbor
      register: ospf_pre

    - name: Pre-check - count FULL neighbours
      ansible.builtin.set_fact:
        neighbours_before: "{{ ospf_pre.stdout[0] | regex_findall('FULL') | length }}"

    - name: Pre-check - make sure OSPF is healthy before we touch it
      ansible.builtin.assert:
        that:
          - neighbours_before | int > 0
        fail_msg: "No FULL OSPF neighbours before the change. Not touching this router."
        success_msg: "{{ neighbours_before }} FULL neighbours before the change."

    # ---------- CHANGE + POST-CHECK ----------
    - name: Make the change, roll back if the post-check fails
      block:
        - name: Change - set OSPF cost
          cisco.ios.ios_config:
            parents: "interface {{ change_interface }}"
            lines:
              - "ip ospf cost {{ new_cost }}"

        - name: Wait for OSPF to settle
          ansible.builtin.pause:
            seconds: 15

        - name: Post-check - get OSPF neighbours
          cisco.ios.ios_command:
            commands: show ip ospf neighbor
          register: ospf_post

        - name: Post-check - count FULL neighbours
          ansible.builtin.set_fact:
            neighbours_after: "{{ ospf_post.stdout[0] | regex_findall('FULL') | length }}"

        - name: Post-check - no neighbours lost
          ansible.builtin.assert:
            that:
              - neighbours_after | int >= neighbours_before | int
            fail_msg: "Neighbours dropped from {{ neighbours_before }} to {{ neighbours_after }}!"
            success_msg: "Still {{ neighbours_after }} FULL neighbours. Change is good."

      rescue:
        - name: Roll back - remove the cost change
          cisco.ios.ios_config:
            parents: "interface {{ change_interface }}"
            lines:
              - "no ip ospf cost {{ new_cost }}"

        - name: Stop the play and report the failure
          ansible.builtin.fail:
            msg: "Change rolled back on {{ inventory_hostname }} because OSPF neighbours dropped."

    - name: Save config (only reached if everything passed)
      cisco.ios.ios_config:
        save_when: modified
```

### Section by section

**`hosts: R1`.** Start with one router. For a real change you'd widen this
carefully, one router at a time (`serial: 1`).

**`vars:`.** What the change is. To reuse the playbook for another interface or
cost, change the values here or pass them on the command line with `-e`.

**Pre-check.**

| Task | What it does |
|---|---|
| `ios_command` + `register: ospf_pre` | Runs `show ip ospf neighbor` and saves the output |
| `regex_findall('FULL') \| length` | Finds every "FULL" in the output and counts them |
| `assert` | If there are 0 FULL neighbours, stop. Never change a router that's already broken |

Example output being counted:

```
Neighbor ID     Pri   State           Dead Time   Address         Interface
10.255.0.2        0   FULL/  -        00:00:35    10.0.12.2       GigabitEthernet2
10.255.0.4        0   FULL/  -        00:00:33    10.0.41.1       GigabitEthernet3
10.255.0.3        0   FULL/  -        00:00:31    10.0.13.2       GigabitEthernet4
```

`neighbours_before` = 3. A neighbour stuck in `INIT` or `EXSTART` isn't counted,
which is what you want.

**`block:`.** The change and the post-check. If **any** task in the block fails,
including the `assert`, Ansible jumps straight to `rescue:`.

**`rescue:`.** Undo the change with `no ip ospf cost`, then use `fail` to stop the
play with a clear message. Without the `fail`, the play would carry on and look
successful.

**Save config.** This only runs if everything passed. A bad change is never saved
to startup-config, so a reload would also undo it.

### `| int`: why it's there

`set_fact` stores the count as text. `| int` turns it into a number, so `>=` compares
numbers. Without it, `"10" >= "9"` is false, because text compares character by character.

## Run it

```bash
ansible-playbook ospf-change.yml --syntax-check
ansible-playbook ospf-change.yml
```

## What you should see

**The good path:**

```
TASK [Pre-check - make sure OSPF is healthy before we touch it]
ok: [R1] => "msg": "3 FULL neighbours before the change."
TASK [Change - set OSPF cost]                    changed: [R1]
TASK [Wait for OSPF to settle]                   (15 second pause)
TASK [Post-check - no neighbours lost]
ok: [R1] => "msg": "Still 3 FULL neighbours. Change is good."
TASK [Save config (only reached if everything passed)]
```

**Test the rollback.** Make the change break something on purpose by shutting the
interface, which drops the R2 neighbour. Ansible connects to R1 on its loopback
(10.255.0.1), so only do this if your Ansible machine can still reach R1 **without**
going through R1's Gi2 (for example, via R3 or R4). Otherwise you'll cut off your
own connection, and the rollback can't run. Add this
to the change task's `lines:` list:

```yaml
              - shutdown
```

Add the matching undo (`no shutdown`) to the rescue task's `lines:` list, then run it. You'll see:

```
TASK [Post-check - no neighbours lost]
fatal: [R1]: FAILED! => "msg": "Neighbours dropped from 3 to 2!"
TASK [Roll back - remove the cost change]        changed: [R1]
TASK [Stop the play and report the failure]
fatal: [R1]: FAILED! => "msg": "Change rolled back on R1 because OSPF neighbours dropped."
```

Remove the `shutdown` lines afterwards.

## Try this

1. Make the check stricter: also assert that a specific neighbour, `10.255.0.2`, is present: `ospf_post.stdout[0] is search('10.255.0.2')`.
2. Run against `core_hosts` with `serial: 1` added under `hosts:`. Routers are changed one at a time, and if R1 fails, R2 is never touched.
3. Pass the values on the command line: `ansible-playbook ospf-change.yml -e new_cost=20`.
4. Replace the 15-second `pause` with `ios_command` plus `wait_for`, so it waits *until* the neighbours are FULL. (`wait_for` is used in Project 1.)

## Common mistakes

| Mistake | Fix |
|---|---|
| Assert always fails | Print the output with `debug: var=ospf_pre.stdout[0]` and check what you're counting |
| Rollback doesn't happen | The change task must be **inside** `block:`, with `rescue:` at the same indent as `block:` |
| Play shows success after a rollback | You need the `fail` task at the end of `rescue:` |
| Comparing counts gives odd results | Add `\| int` on both sides |
