# 3.1 ios_config with backup

**Task:** deploy an ACL, backing up the config first.

## What you'll learn

| Concept | In one line |
|---|---|
| `backup: true` | Saves the running config to your computer **before** making changes |
| `backup_options` | Chooses where the backup goes and what it's called |
| `parents:` | The config "mode" the lines go under (here, the ACL) |

## Files

```
ansible-lab/
├── acl.yml                       <- NEW
└── backups/                      created by the playbook
    ├── R1-before-acl.cfg
    └── R2-before-acl.cfg
```

## The files explained

### `acl.yml`

```yaml
---
- name: Deploy management ACL (backup first)
  hosts: core_hosts
  gather_facts: false

  tasks:
    - name: Deploy ACL and back up the config first
      cisco.ios.ios_config:
        backup: true
        backup_options:
          dir_path: backups
          filename: "{{ inventory_hostname }}-before-acl.cfg"
        parents: ip access-list extended MGMT-IN
        lines:
          - 10 permit tcp 10.0.0.0 0.0.255.255 any eq 22
          - 20 permit icmp any any
          - 30 deny ip any any log
      notify: Save config

  handlers:
    - name: Save config
      cisco.ios.ios_config:
        save_when: modified
```

| Line | What it does |
|---|---|
| `backup: true` | Grab the full running config first, then make the change |
| `dir_path: backups` | Save backups in `backups/` in your project |
| `filename: "{{ inventory_hostname }}-before-acl.cfg"` | One clearly named file per router |
| `parents: ip access-list extended MGMT-IN` | Enter ACL mode first, then send the lines under it |
| `lines:` | The ACL entries, written exactly as `show running-config` shows them (see the note below) |

What Ansible actually sends:

```
ip access-list extended MGMT-IN
 10 permit tcp 10.0.0.0 0.0.255.255 any eq 22
 20 permit icmp any any
 30 deny ip any any log
```

### Match your running config exactly

IOS-XE (CSR1000v, Cat8000v) shows sequence numbers (`10 permit ...`) in the running
config for named ACLs. Older classic IOS doesn't. Check yours:

```
R1# show running-config | section MGMT-IN
```

If your router doesn't show sequence numbers, remove them from `lines:`. If you
don't, `ios_config` never finds a match and reports `changed` on every run (lesson 2.3).

### How `parents` works

`ios_config` reads the running config as a tree:

```
ip access-list extended MGMT-IN        <- parent
 10 permit tcp 10.0.0.0 ...            <- child line
 20 permit icmp any any                <- child line
```

It only sends the child lines that are missing under that parent. Interfaces,
router ospf, line vty and so on all work the same way.

## Run it

```bash
ansible-playbook acl.yml --check --diff
ansible-playbook acl.yml
ls backups/
```

## What you should see

- `backups/R1-before-acl.cfg` and `backups/R2-before-acl.cfg` contain the full running config from **before** the change.
- On the router:
  ```
  R1# show ip access-lists MGMT-IN
  ```
- Run it again: `changed=0`. A backup is still taken every run, so you always have the latest.

This ACL is only **created**, not applied to an interface or the vty lines, so it
can't lock you out. Applying ACLs is where people cut off their own access. Practise
on a lab interface first.

## Rolling back with the backup

If a change goes wrong, you have the "before" config. In the lab, to restore the ACL
section by hand:

1. Open the backup and find the old `ip access-list extended MGMT-IN` block (if there was one).
2. Remove the new ACL: `no ip access-list extended MGMT-IN`.
3. Paste the old block back.

Lesson 3.3 automates rollback for a specific change.

## Try this

1. Add `25 permit udp any any eq 123` (NTP). Sequence 25 slots it between 20 and 30. Check the order with `show ip access-lists MGMT-IN`.
2. Remove `backup_options` entirely. Where does the backup go now? (Look for a `backup/` folder with a timestamped name.)
3. Change `hosts:` to `routers` so the edge routers get it too.

## Common mistakes

| Mistake | Fix |
|---|---|
| Always `changed` | Your lines don't match how your IOS version stores the ACL. Compare with `show running-config \| section MGMT-IN` and copy that format |
| Lines end up in global config | `parents:` must be the exact line IOS shows, e.g. `ip access-list extended MGMT-IN` |
| Backups overwrite each other | That's what a fixed `filename` does. Add a date if you want history, or use Git (lesson 4.1) |
